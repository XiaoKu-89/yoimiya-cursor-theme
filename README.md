## 📦 包含内容

全套 **12 种** Windows 常用光标，覆盖日常操作全场景：

| 光标类型 | 说明 |
|---|---|
| 🖱️ 正常指针 | 日常操作默认光标 |
| ❓ 帮助/位置选择 | 带问号的选择状态 |
| ⏳ 在后台工作 | 后台运行中（箭头+小圈） |
| 🔄 忙 | 等待/忙碌（转圈动画） |
| 🚫 不可用 | 禁止操作 |
| ✏️ 文本选择 | 文字编辑时的 I 型光标 |
| 🔗 链接选择 | 指向超链接的手型光标 |
| ↕️ 垂直调整大小 | 上下拖拽边框 |
| ↔️ 水平调整大小 | 左右拖拽边框 |
| ↗️ 对角线调整 1 | 斜向拖拽（↘） |
| ↙️ 对角线调整 2 | 斜向拖拽（↙） |
| ✥ 移动 | 四向移动光标 |

两种尺寸：**64×64**（标准屏）和 **128×128**（高分屏）。

## 🔧 安装方法

### 方法一：逐个设置（推荐，可自由搭配）

1. 按 `Win + I` →「蓝牙和其他设备」→「鼠标」→「其他鼠标设置」
2. 切换到「指针」选项卡
3. 在自定义列表中选中要替换的光标 →「浏览」→ 选择对应 `.cur` 文件
4. 逐一替换后点击「另存为」保存方案
5. 点击「确定」生效

### 方法二：一键安装（进阶）

为文件夹编写 `.inf` 安装信息文件后，右键即可一键安装整套主题。
